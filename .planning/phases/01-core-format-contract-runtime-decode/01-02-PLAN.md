## Phase Goal

**As a** Unity game developer, **I want to** lock the NAMER packed surface format in a pure-C# Core assembly and decode it correctly in a URP runtime shader, **so that** NAMER materials render equivalently to the Blender NAMER reference implementation.

<objective>
Port the locked Core format contract (plan 01-01) into a hand-written URP runtime shader that decodes the packed surface texture at render time, and verify it renders comparably to URP Lit on the same source material.

Purpose: This proves the decode side of the walking skeleton (Core encode → packed bytes → shader decode → visually verifiable render). The shader reuses URP's `UniversalFragmentPBR` lighting (so SHDR-03 is an apples-to-apples comparison against URP Lit) but replaces texture sampling with NAMER decode. Vertex-color reconstruction (SHDR-02, D-05) is wired from day one even though decomposition lands in Phase 4.

Output: `Shaders/NAMER.shader` (ShaderLab + HLSLPROGRAM, all required URP passes), `Shaders/NamerSurface.hlsl` (the decode + surface-data assembly), and `Editor/NamerSmokeSetup.cs` (an editor script that configures URP and builds the smoke-test scene/material for the visual check).
</objective>

From Core (C# reference — the shader is a hand-port of the same math):
```csharp
float2 OctahedralEncode(float3 v);   // oct = 0.5 + 0.5*v.xy/(v.x+v.y+v.z)
float3 OctahedralDecode(float2 oct); // full quadratic inverse; n.y = 1 - p.y*S (DirectX green un-flip)
byte   PackAlphaBits(metallic>0.5 ? 0x80, emissive>0.1 ? 0x40, floor(roughness*63) in 0x3F)
```

URP ShaderLibrary functions the shader MUST reuse (do not hand-roll):
```hlsl
#include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Core.hlsl"
#include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Lighting.hlsl"
// GetVertexNormalInputs(), TransformTangentToWorld(), UniversalFragmentPBR(), SurfaceData, InputData
```

Shader identifier: `Shader "GraffitiEntertainment.Namer/NAMER"` (referenced by the smoke test via `Shader.Find`).
Properties: `_SurfaceMap` (linear UNorm, packed), `_BaseResidualMap` (sRGB, base/residual color), `_BaseColor`, `_EmissionColor` (HDR), `_OcclusionStrength`.
</interfaces>

Load-bearing facts (from 01-RESEARCH.md "Architecture Patterns" Pattern 3 and "Code Examples" section 4):
- Passes (LightMode tags) to replicate from URP 17 `Lit.shader`: ForwardLit `UniversalForward`, ShadowCaster `ShadowCaster`, DepthOnly `DepthOnly`, DepthNormals `DepthNormals`, Meta `Meta`; GBuffer `UniversalGBuffer` and Universal2D `Universal2D` are optional stubs.
- Keywords: `_SURFACE_TYPE_TRANSPARENT`, `_ALPHATEST_ON`, `_ALPHAPREMULTIPLY_ON`, `_ALPHAMODULATE_ON`, `_EMISSION`, `_RECEIVE_SHADOWS_OFF`, `_SPECULARHIGHLIGHTS_OFF`, `_ENVIRONMENTREFLECTIONS_OFF`, plus URP pipeline `multi_compile` (lights, shadows, SH, fog, instancing). NAMER does NOT need `_NORMALMAP`/`_METALLICSPECGLOSSMAP`/`_OCCLUSIONMAP`.
- SurfaceData mapping: `albedo = baseResidual.rgb * vertexColor.rgb`, `normalTS = NamerOctahedralDecode(surface.rg)`, `metallic = bit7 ? 1 : 0`, `smoothness = 1.0 - roughness` (NAMER stores ROUGHNESS, not smoothness), `occlusion = surface.b * _OcclusionStrength`, `emission = _EmissionColor.rgb * (bit6 ? 1 : 0)`, `alpha = baseResidual.a`.
- The packed surface texture is LINEAR data (ENCD-04): sample R/G/B as data, never sRGB. Alpha (packed bits) is always linear regardless.
</context>
