## Phase Goal

**As a** Unity game developer, **I want to** lock the NAMER packed surface format in a pure-C# Core assembly and decode it correctly in a URP runtime shader, **so that** NAMER materials render equivalently to the Blender NAMER reference implementation.

<objective>
Scaffold the Unity project and the UPM package `com.graffitientertainment.namer` — the foundation every later plan compiles against — and author the round-trip test harness (the walking-skeleton end-to-end slice: Core encode → packed bytes → shader decode → render).

Purpose: The research is unambiguous that NO Unity project exists today (repo is PRD + `.sln` stub only), and that project creation must precede any shader compilation or test execution. This plan creates the project, installs URP, and lays down the assembly-definition contracts (Core, Runtime, Editor, Tests) so plans 01-01 (Core math) and 01-02 (shader) have a compile target. The round-trip PlayMode smoke test is authored here as the failing end-to-end test that becomes green only after 01-01 and 01-02 land.

Output: a Unity project at the repo root, `Packages/manifest.json` with URP, the package `package.json`, five asmdefs, a `README.md`, and the PlayMode round-trip smoke test scaffold.
</objective>
