## Phase Goal

**As a** technical artist using Unity, **I want to** select any supported source (GameObject, prefab, FBX/model, material, or folder) and have NAMER read its PBR maps and produce normalized base-color and packed surface textures entirely on the GPU, **so that** the output is proven equivalent to the CPU reference before asset generation.

<objective>
Build the `SourceInspector` C# API (D-01: API, not UI) that resolves any selection kind into deduplicated unique materials and reads each material's PBR maps and scalar fallbacks through per-shader property-convention tables.

Purpose: This is the CPU half of Phase 2 and the front door of the whole pipeline. It locks the map-discovery conventions (URP Lit `_SmoothnessTextureChannel` indirection, AO-in-G channel) before the GPU kernels consume them, and it produces the serializable `NamerSourceModel` that plans 02-02 (compute pipeline) and 03-01 (asset generation) build against.

Output: `Editor/Pipeline/NamerSourceModel.cs`, `Editor/Pipeline/SourceInspector.cs`, `Tests/Editor/SourceInspectorTests.cs`, and a one-line edit to the Editor test asmdef.
</objective>

<!-- Property tables the executor reads from. Source of truth: 02-RESEARCH.md "Standard Stack". -->

URP Lit ("Universal Render Pipeline/Lit") — use these EXACT names (verified from Lit.shader + LitInput.hlsl):
  _BaseMap (Texture2D) + _BaseColor (Color)
  _BumpMap (Texture2D) + _BumpScale (float)
  _MetallicGlossMap (Texture2D) — R = metallic, A = smoothness
  _Metallic (float), _Smoothness (float)
  _SmoothnessTextureChannel (float) — 0 = metallic-map alpha, 1 = base-map alpha  (NOT _SmoothnessSource)
  _OcclusionMap (Texture2D) — AO = GREEN (.g) channel
  _OcclusionStrength (float)
  _EmissionMap (Texture2D) + _EmissionColor (Color)
  _Surface (float 0/1), _Cutoff (float)

Unity Standard ("Standard") — HIGH confidence (A1), guarded by Material.HasProperty:
  _MainTex + _Color
  _BumpMap + _BumpScale
  _MetallicGlossMap (R = metallic, A = smoothness) + _Metallic + _Glossiness + _GlossMapScale
  _OcclusionMap (G = AO) + _OcclusionStrength
  _EmissionMap + _EmissionColor
  _Cutoff

Neutral defaults (D-07): metallic 0, roughness 0.5, AO 1.0, emission black, normal (0,0,1).
Roughness = 1 - smoothness (D-05); AO = raw _OcclusionMap.g (do NOT bake _OcclusionStrength — record it as metadata for Phase 3).

Namespaces: Editor = GraffitiEntertainment.Namer.Editor, Tests = GraffitiEntertainment.Namer.Tests, Core = GraffitiEntertainment.Namer.Core.
