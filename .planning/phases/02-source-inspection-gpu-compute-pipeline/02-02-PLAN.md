## Phase Goal

**As a** technical artist using Unity, **I want to** select any supported source (GameObject, prefab, FBX/model, material, or folder) and have NAMER read its PBR maps and produce normalized base-color and packed surface textures entirely on the GPU, **so that** the output is proven equivalent to the CPU reference before asset generation.

<objective>
Build the GPU compute half of Phase 2: a shared HLSL encode include that mirrors `Core/NamerFormat` line-for-line, three staged kernels in the existing `Compute/NAMERPack.compute`, a `ComputeTexturePool` for RenderTexture lease/reuse, and a `NamerComputePipeline` dispatch harness that turns a `NamerSourceModel` inspection into in-memory normalized base-color and packed surface textures.

Purpose: This is the performance-critical path (NORM-03) and the format-fidelity bridge between the CPU reference and the GPU. Every kernel must be a mirror of `NamerFormat`, never a re-derivation, so the 02-03 golden tests can prove byte-level equivalence. The metallic/smoothness MAP path is wired end-to-end (D-05), not just scalar fallbacks. Apply the D-16 rename while writing the kernels that call the renamed method. The `_BaseColor` tint is intentionally NOT baked into the normalized texture — it stays as material metadata on the runtime NAMER shader's `_BaseColor` property (same convention as emissive color as metadata).

Output: `Compute/NamerEncode.hlsl`, `Compute/NAMERPack.compute` (filled), `Editor/Pipeline/ComputeTexturePool.cs`, `Editor/Pipeline/NamerComputePipeline.cs`, and a one-line rename in `Core/NamerFormat.cs`.
</objective>

<!-- Core encode math to mirror EXACTLY (from Core/NamerFormat.cs + Core/NamerConstants.cs). -->
NamerFormat.OctahedralEncode(float3 v):  sum = max(v.x+v.y+v.z, Epsilon); return (0.5 + 0.5*v.x/sum, 0.5 + 0.5*v.y/sum)
NamerFormat.PackAlphaBits(metallic, emissive, roughness): metallicBit = metallic > 0.5 ? 0x80 : 0; emissiveBit = emissive > 0.1 ? 0x40 : 0; roughnessBits = clamp((int)floor(roughness*63), 0, 0x3F); return metallicBit | emissiveBit | roughnessBits
NamerFormat.PackSurface(normalTexel, ao, metallic, emissive, roughness): oct = OctahedralEncode(normalTexel); alpha = PackAlphaBits(...)/255; return float4(oct.x, oct.y, ao, alpha)

NamerConstants: MetallicBit 0x80, EmissiveBit 0x40, RoughnessMask 0x3F, MetallicThreshold 0.5, EmissiveThreshold 0.1, RoughnessLevels 63.0, AlphaByteScale 255.0, Epsilon 1e-6.

<!-- NamerSourceModel (from 02-01) consumed by NamerComputePipeline.Process -->
NamerMaterialInspection fields: BaseMap, BaseMapIsSrgb, BaseColor, NormalMap, BumpScale, MetallicGlossMap, Metallic, Smoothness, SmoothnessTextureChannel, OcclusionMap, OcclusionStrength, EmissionMap, EmissionColor, Emissive (max emission color component or 0), Roughness (already 1 - Smoothness), AoUnmultiplyStrength (default 1.0).

<!-- HLSL helper for sRGB->linear: defined at line 77 of the installed RP core Color.hlsl. -->
SRGBToLinear(real c): c <= 0.04045 ? c/12.92 : pow((c+0.055)/1.055, 2.4)   (exact IEC 61966-2-1 curve)

<!-- GraphicsFormat contracts (D-11). -->
Intermediates: GraphicsFormat.R16G16B16A16_SFloat (linear). Final packed surface: GraphicsFormat.R8G8B8A8_UNorm (linear). Never sRGB as a compute write target.
