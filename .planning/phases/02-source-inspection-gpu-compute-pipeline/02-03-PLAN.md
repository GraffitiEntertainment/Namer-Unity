## Phase Goal

**As a** technical artist using Unity, **I want to** select any supported source (GameObject, prefab, FBX/model, material, or folder) and have NAMER read its PBR maps and produce normalized base-color and packed surface textures entirely on the GPU, **so that** the output is proven equivalent to the CPU reference before asset generation.

<objective>
Prove the Phase 2 GPU kernels are a faithful mirror of `Core/NamerFormat`: kernel golden tests compare `CSNormalize`, `CSOctahedralEncode`, and `CSSurfacePack` against the CPU oracle with D-14 tolerances, and a capability-gated cross-platform smoke test runs the full `NamerComputePipeline` (upload -> normalize -> octahedral -> pack -> readback) plus a RenderTexture leak watchdog.

Purpose: This is the TEST-04 gate — the proof that the GPU path does not drift from the CPU reference (Pitfall 3/Pitfall 9). It is the only part of Phase 2 that exercises the actual GPU, and it is capability-gated so a machine without compute/async-readback skips with an explicit report (D-15: Metal is the verified target, CI matrix is v2). It also covers the highest color-correctness risk (CSNormalize sRGB->linear + AO un-multiply, Pitfall 1) and the metallic/smoothness map path.

Output: `Tests/Editor/GpuGoldenTests.cs` and `Tests/Editor/ComputeSmokeTests.cs`.
</objective>

<!-- Core oracle the golden tests compare against (from Core/NamerFormat.cs). -->
NamerFormat.OctahedralEncode(float3 v) -> float2 oct
NamerFormat.PackAlphaBits(metallic, emissive, roughness) -> byte
NamerFormat.PackSurface(float3 normalTexel, ao, metallic, emissive, roughness) -> float4 (rg=oct, b=ao, a=packedAlpha/255)

<!-- D-14 tolerance semantics. -->
packed alpha byte: EXACT (Assert.AreEqual on Color32.a vs NamerFormat.PackAlphaBits)
octahedral R/G + AO: within 1/255.0 (8-bit quantization of the R8G8B8A8_UNorm write)
decoded normal dot: >= 1 - 1e-3 (Phase 1 convention)

<!-- Compute resource names to bind (from NAMERPack.compute, read it for exact types). -->
Uploaded inputs: _NormalTexel, _AoIn, _BaseColorIn, _MetallicGlossIn
Kernel outputs/intermediates: _BaseColorOut, _Octahedral, _PackInputs, _SurfaceOut
Uniforms: _Size (int2), _SourceIsSrgb, _AoUnmultiplyStrength, _Metallic, _SmoothnessScalar, _Roughness, _Emissive, _SmoothnessTextureChannel, _HasMetallicGlossMap

<!-- sRGB decode oracle for the CSNormalize golden (exact IEC 61966-2-1 curve, matches RP core Color.hlsl line 77). -->
SRGBToLinear(c) = c <= 0.04045 ? c/12.92 : pow((c + 0.055)/1.055, 2.4)
AO un-multiply oracle: cleaned = base / lerp(1.0, max(ao, 1e-6), strength)
