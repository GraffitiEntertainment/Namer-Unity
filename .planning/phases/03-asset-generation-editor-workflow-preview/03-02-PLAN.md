## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| selection/controls -> window | Untrusted selection, user-entered destination/prefix/suffix, and AO-slider values cross into the window |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-06 | DoS | unbounded RT allocation across debounced re-dispatches | mitigate | `ReleaseResult` before each recompute; at most one live result; `OnDisable` disposes preview/pipeline (Pitfall 5 leak-watchdog) |
| T-03-07 | Tampering | interactive preview writing to disk | mitigate | preview path calls only `NamerComputePipeline`/`NamerPreviewRenderer`; never `NamerProcessor`/`AssetGenerator` (D-10) |
| T-03-08 | Input Validation (V5) | unsupported/empty selection or invalid destination | mitigate | selection resolved via `SourceInspector` (warns, never throws); destination validated in `NamerProcessor` (03-01); window shows error HelpBox states |
| T-03-09 | Integrity | pink/fallback-error preview (URP not active) | mitigate | `Render(true)` on every preview render; window detects/warns if no URP asset is active in Graphics settings (Pitfall 1) |
| T-03-SC | Tampering | package installs | accept | zero new packages this plan (Unity Editor + BCL only) |
