## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] AO average readback averaged stale texels of the over-allocated avg target**

- **Found during:** Task 3 test run (`Extraction_ProducesNonWhiteAo_WhenNoOcclusionMap` failed: dark region AO came out white)
- **Issue:** `ReduceToScalarMean` leases the ping-pong average targets at the first reduced size (e.g. 8×8), but the final reduction writes only the top-left `srcW × srcH` region (e.g. 1×1). The scalar-mean readback averaged the *entire* RT, including stale/garbage texels, corrupting `_LumaAverage` and collapsing the extraction to white for non-uniform bases.
- **Fix:** Pass `srcW`/`srcH` into `ReadBackLumaAverage` and sum only the valid top-left region using `src.width` as the row stride.
- **Files modified:** `Packages/com.graffitientertainment.namer/Editor/Pipeline/NamerAOPipeline.cs`
- **Verification:** Full EditMode suite re-run green (63/63 passed, 0 failed).
- **Committed in:** `91163e9` (fix)
