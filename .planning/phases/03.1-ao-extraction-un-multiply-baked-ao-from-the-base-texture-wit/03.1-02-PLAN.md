<objective>
Build the second AO source — the geometry bake ("cubemap of light") — as a deterministic CPU Burst raycast subsystem, AND wire it into `NamerComputePipeline.Process` so it actually reaches `_AoIn` and the packed B channel. The bake reconstructs a world position + interpolated normal per UV-covered texel, offsets outward by the cage offset (0.01), casts 64 directions against a BVH over the occluder mesh, and stores `unoccluded / 64` as AO. The selected mesh is the default bake source (D-03) with an optional high-res occluder override that needs no UV match (D-04); a null/invalid occluder falls back to the selected mesh with a warning, never a hard failure (D-06). `NamerComputePipeline.Process` becomes a three-way source gate — authored map (byte-identical), cached bake (supersedes extraction), image-space extraction (when no bake is cached yet) — so the bake result is not dead code. The bake runs reduced-resolution, is cached per (mesh, occluder, params), and is never re-run on the 300 ms debounce tick.

Purpose: Replicate the Blender Cycles AO bake defaults (D-05) inside Unity without Cycles, deterministically and headless-testable, and route the result end-to-end into the packed surface — the phase-title deliverable "geometry bake" is only complete when the bake reaches `_AoIn`.

Output: `Editor/Bake/NamerAOBvh.cs`, `Editor/Bake/NamerAOBaker.cs`, edits to `Editor/Pipeline/NamerSourceModel.cs`, `Compute/NAMERAO.compute` (JFA kernels), `Editor/Pipeline/NamerAOPipeline.cs` (bake integration), `Editor/Pipeline/NamerComputePipeline.cs` (three-way source gate), and `Tests/Editor/NamerAOBakeTests.cs`.
