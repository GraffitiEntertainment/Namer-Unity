<objective>
Build the GPU side of vertex-color decomposition: rasterize the quantized Color32 vertex colors into UV space, divide the linear base by the interpolated color to form the multiplicative quotient residual, compute the reconstruction error (coverage/avg/max) with one consistent mean-channel MAE metric, and run the adaptive downward-halving residual-resolution search with a manual ladder override (VCOL-03/VCOL-04/VCOL-05). The residual is the quotient — NOT a subtractive difference — because the runtime shader multiplies (`albedo = baseResidual.rgb * _BaseColor.rgb * vertexColor.rgb`, `NamerSurface.hlsl:94`), and it must be derived from the QUANTIZED Color32 (what the runtime actually interpolates), never the float fit (Pitfall 2).

Purpose: Produce the residual texture + error statistics + resolution decision as GPU compute, so reconstruction `vcInterp_q × residual ≈ base` holds end-to-end and the no-texture endgame (D-13) has a measurable gate.

Output: `Compute/NAMERDecomp.compute`, `Compute/NAMERDecomp.hlsl`, edit to `Core/NamerConstants.cs` (VcFloor), `Editor/Decompose/NamerDecompPipeline.cs`, `Tests/Editor/ResidualPipelineTests.cs`.
</objective>
