<objective>
Close two Phase-4 verification gaps found by the code verifier, both silent-wrong-output defects at the seams of the completed 04-01/02/03 work:

- **CR-01 (VCOL-01):** `NamerProcessor.Process` resolves ONE mesh for the whole selection and `BindGeneratedMaterials` last-write-wins the `generatedMeshBySourceMeshId` dictionary, so a multi-material mesh (or multi-mesh selection) renders wrong vertex colors while Process reports success.
- **CR-02 (VCOL-05):** `AssetGenerator.WriteResidualExr` stamps the residual EXR `FilterMode.Point` while the adaptive resolution search and the reported `MaxError` assume bilinear runtime sampling, so reduced-resolution saved materials render blocky and exceed the reported error.

Purpose: Eliminate two silent-wrong-output root causes with the smallest possible changes, each paired with a regression test that would have failed before the fix.

Output: edits to `NamerProcessor.cs` (CR-01 guard), `AssetGenerator.cs` (CR-02 one-line filter mode change), and two new `[UnityTest]` regression cases in `NamerDecompIntegrationTests.cs`.
</objective>
