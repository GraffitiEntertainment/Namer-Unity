<objective>
Close the third Phase-4 verification gap — CR-03 (VCOL-04), the most subtle silent-wrong-output defect:

- UVs outside [0,1] (tiling layouts) rasterize to zero coverage in `CSRasterizeVertexColors`; uncovered texels write `_ErrorStat = (0,0,0,1)`, which the D-13 drop gate reads as a perfect opaque fit (`MaxError=0`, `MinAlpha=1`) and silently drops the residual — while the CPU fitter clamps out-of-range UVs to edge texels and writes garbage vertex colors. Process reports success with no residual and wrong output.

Two coordinated fixes, per the verifier's `missing` list: (1) make the CPU `SampleBase` wrap (Repeat) so the fit matches runtime sampling, and (2) guard the D-13 gate on coverage so a near-zero-coverage fit is flagged `CannotDecompose` and `NamerProcessor` falls back to the non-decomposed Phase-3 shape with a warning.

Purpose: Eliminate the silent zero-coverage "perfect fit" blind spot and make the CPU fit consistent with runtime Repeat sampling.

Output: edits to `VertexColorFitter.cs` (wrap), `NamerDecompPipeline.cs` (coverage guard + `CannotDecompose`), `NamerProcessor.cs` (fallback branch), and two regression tests (a headless wrap test in `VertexColorDecompTests.cs` and a tiling-UV integration test in `NamerDecompIntegrationTests.cs`).
</objective>
