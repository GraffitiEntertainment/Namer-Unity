# Phase 4 — UI Design Contract

> Visual and interaction contract for the vertex-color decomposition + residual extension to the existing `Tools > NAMER > Processor` editor window. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **This phase EXTENDS the Phase-3 editor window — it does not create a new surface.** The approved baseline is `.planning/phases/03-asset-generation-editor-workflow-preview/03-UI-SPEC.md`; every token there (layout regions, control styling, debug-toolbar convention, before/after split, 300 ms debounced-recompute model) is inherited unless a field below overrides it. This phase adds: the opt-in decomposition toggle + error threshold + residual-resolution ladder (D-05/D-15/D-17), the live statistics block (D-09/D-12), the three new debug channels (D-10/D-11), and the post-generation vertex-coloring on/off behavior (D-14/D-08).
>
> **This is a Unity Editor plugin, not a web frontend.** The "design system" is Unity's native editor chrome (IMGUI + `GUISkin`/`EditorStyles`). No shadcn, no CSS, no external component/icon library. Every token below is expressed in Unity Editor terms (`EditorGUILayout`, `HelpBox`, `Toolbar`, `PreviewRenderUtility`) and inherits Unity's native look (`EditorGUIUtility.isProSkin`).

## Color

Unchanged from Phase 3. Colors are inherited from Unity's editor skin (`GUI.skin` + `EditorGUIUtility.isProSkin`) — **never hard-coded**. Representative hexes document the dark/light appearance for reference only.

| Role | Source (single truth) | Representative hex (dark / light) | Usage |
|------|----------------------|-----------------------------------|-------|
| Dominant (60%) | `GUISkin.window` background | `#383838` / `#C8C8C8` | Window and preview-pane background |
| Secondary (30%) | `EditorStyles` field/box backgrounds | `#2C2C2C` / `#F0F0F0` | Section boxes, preview pane framing, HelpBox surfaces, field backgrounds |
| Accent (10%) | Unity selection/focus blue (`GUI.skin.settings.selectionColor` + focus) | `#007ACC` / `#007ACC` | Primary CTA focus/active, active debug-channel toolbar item, focused field outline |
| Destructive | HelpBox error color | `#CC3333` / `#CC3333` | Error HelpBox, overwrite-refusal message, readback-failed status |

**Accent reserved for (unchanged explicit list — the new controls add NO accent usage):**
1. The **"Process with NAMER"** primary button's focused/active state.
2. The **active (selected) debug-channel toolbar** item.
3. The **focused field** outline on destination / prefix / suffix.

**Destructive reserved for (unchanged explicit list):**
1. **Overwrite-refusal** error HelpBox (non-stamped collision).
2. **Readback-failed** error status (`request.hasError`).
3. **Unsupported/empty selection** blocking errors.

**Data-visualization ramp (NOT a UI color — appears only inside the rendered preview texture, never in IMGUI chrome):**
The Error Heatmap debug channel uses a **perceptually-uniform viridis-style ramp** (D-11), not grayscale and not the UI accent. Anchor colors, applied in GPU compute to normalized error magnitude [0 → 1]:

| Error | Ramp anchor |
|-------|-------------|
| 0.0 | `#440154` (deep violet) |
| 0.25 | `#3B528B` (blue) |
| 0.5 | `#21918C` (teal) |
| 0.75 | `#5EC962` (green) |
| 1.0 | `#FDE725` (yellow) |

Zero error maps to the low (violet) end; the max observed error maps to the high (yellow) end. This ramp is data-viz, not decoration, and is excluded from the 60/30/10 UI color budget.

## Interaction Contract

All Phase-3 interactions are inherited unchanged. Phase 4 adds the following:

- **Decomposition toggle change → debounced recompute (D-08/D-12):** mark dirty; after **300 ms** (`NamerEditorConstants.DebounceSeconds = 0.3f`, same named constant) of no further change, re-run the decomposition fit + residual generation in memory and `Repaint()`. **Never writes to disk** (D-10). When enabled, the after pane shows the decomposed reconstruction — preview parity with generated output (D-08).
- **Error threshold change → debounced recompute:** same 300 ms debounce; re-runs the adaptive residual-resolution search (D-16) and refreshes the statistics block (D-12).
- **Residual resolution change → debounced recompute:** same 300 ms debounce; re-generates the residual at the chosen ladder step.
- **D-14 on/off switch (post-generation):** the decomposition toggle is ALSO the "use vertex colors" switch. When generated assets already exist for the selection, flipping the toggle re-binds the after pane to the matching generated representation (decomposed split-mesh + residual, or non-decomposed original mesh + Base PNG) instantly — **no reprocessing** (D-14). The generated/live flip mechanism extends the existing `NamerAfterPanelState` (`PreferGenerated` / `MarkTweaking`), not a new state machine.
- **Statistics update (D-12):** every debounced recompute refreshes Coverage / Avg Error / Max Error / Residual / Residual Resolution in place; no separate refresh button.
- **Debug channel picker:** switches only the **after** pane (unchanged). The toolbar now has 10 modes (see Debug Channel Contract). "Shaded" (default) renders the real NAMER material; the nine channel modes render the editor-only debug shader.
- **No dead controls (D-14 carry-in):** when the decomposition toggle is OFF, the Error Threshold slider and Residual Resolution dropdown are disabled (grayed) and the statistics block is hidden — they have no meaning without decomposition. When there is no material or the window is Busy, the whole Processing section is disabled (existing pattern).

## State Contract

Phase-3 states are inherited; two are extended and one row (statistics) is added.

| State | Trigger | UI behavior |
|-------|---------|-------------|
| Empty | No selection | Source "—"; preview empty-state; Process disabled |
| Inspecting | Selection changed | Source refresh; summary rebuild; Process disabled until ready |
| Ready | Valid inspection + preview rendered | All controls enabled; Process enabled |
| Recomputing | AO slider, decomposition toggle, threshold, or resolution change (debounce) | Debug toolbar + Processing controls stay enabled; Process disabled; preview shows previous frame until fit/readback completes; statistics show previous values |
| Busy / Processing | Process clicked | Button reads "Processing…"; all controls disabled; status line "Processing {n} material(s)…" |
| Success | Writes complete | Status "Generated {n} material(s) under {destination}."; controls re-enabled; after pane flips back to generated (`_afterPanelState.Reset()`) |
| Error | `request.hasError`, overwrite refusal, or unsupported selection | Error HelpBox (destructive); controls re-enabled; no assets written |
| Statistics (toggle ON) | Fit completes after any debounced recompute | Coverage/Avg/Max Error/Residual/Residual Resolution populated; "Residual" shows "not required" when fit ≤ threshold (D-13) |
| Statistics (toggle OFF) | Toggle off | Statistics block hidden; threshold + resolution disabled |

## Debug Channel Contract

The debug picker grows from **7 modes to 10** (D-10). The debug shader (`NamerDebugView.shader`) must keep `#include "NamerSurface.hlsl"` and call `NAMER_DECODE_SURFACE` so views cannot drift from runtime decode. Three channels are appended after Emissive; the existing six keep their `_DebugChannel` values.

| UI label | Mode | `_DebugChannel` | Renders |
|----------|------|-----------------|---------|
| Shaded | runtime NAMER material (default) | n/a | lit NAMER result |
| Base Color | debug | 0 | normalized base color |
| AO | debug | 1 | occlusion |
| Normal | debug | 2 | decoded octahedral normal |
| Roughness | debug | 3 | roughness (6-bit decoded) |
| Metallic | debug | 4 | metallic flag |
| Emissive | debug | 5 | emissive flag |
| **Vertex Colors** | debug | **6** | the mesh's Color32 stream (RGB), white where no colors are present |
| **Residual** | debug | **7** | the residual texture (base-residual map); equals base color when non-decomposed |
| **Error Heatmap** | debug | **8** | reconstruction error mapped through the viridis ramp (D-11); uniform zero (violet) when non-decomposed |

The three new channels are **always present** in the toolbar (they join the existing list, D-10), and each renders a meaningful fallback when decomposition is off — never a disabled placeholder entry. The debug shader's vertex `Attributes` must gain a `COLOR` semantic to carry the vertex-color stream for channel 6.
