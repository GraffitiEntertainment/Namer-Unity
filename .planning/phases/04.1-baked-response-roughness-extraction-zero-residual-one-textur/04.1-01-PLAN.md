<objective>
Deliver the Sobel (Blender-parity) roughness extraction path end-to-end: a new `NAMERRoughness.compute`/`NAMERRoughness.hlsl` kernel set and `NamerRoughnessPipeline` harness that computes per-texel roughness from the cleaned base's luminance edges, plus the `CSNormalize`/`CSSurfacePack` and `NamerComputePipeline` wiring that routes that roughness into packed surface alpha bits 0-5 when the source has no authored roughness map (D-01).

Purpose: prove the core architectural bet of Phase 04.1 — baked gloss can be read back out of the base texture as roughness values and packed without changing the format contract — on the thinnest path (Sobel only, no strength search yet).

Output: a working Sobel extraction stage wired into the pack pipeline, verified by GPU round-trip tests. No disk writes beyond the test assembly; the fit-driven estimator and one-texture mode are later plans.
</objective>
