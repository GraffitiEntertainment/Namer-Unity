<objective>
Build the fit-driven estimator and the sharp-removal (frequency-separation) stage, and wire the resulting cleaned base into the vertex-color refit so the residual collapses for baked-response assets. Add the D-02/D-03 user controls (strength slider + estimator popup) inside a new Roughness Extraction foldout, and restructure the editor window into D-07 collapsible foldout sections + scrolling so the window fits on screen.

Purpose: turn the Sobel proof (plan 01) into the phase's primary path — the strength search selects the minimal strength that collapses the residual within threshold (ChooseResolution-style, not a global argmin), and the sharp-removal cleaned base is what the refit consumes (D-05), which is the precondition for the one-texture outcome in plan 03. The fit-driven estimator runs only when a refit can run (decomposition enabled AND a source mesh resolved) — otherwise it SKIPs extraction to the identity legacy path (1A) — and `NamerProcessor` composes the fit's `Func<float,float>` evaluate callback (3A).

Output: `NamerRoughnessFitter` (deterministic managed strength ladder), the frequency-separation kernels, the estimator-selection + D-05 wiring in `NamerProcessor`/`NamerComputePipeline`/`NamerRoughnessPipeline` (with the 3A callback-owner + AO-three-way cache contract and the 1A fit-driven gate), the persisted settings + foldout UI controls + extracted-roughness debug channel (D-07), and the fit-driven/D-05/1A default-on tests. The one-texture material binding and D-06 escape hatch are plan 03.
</objective>
