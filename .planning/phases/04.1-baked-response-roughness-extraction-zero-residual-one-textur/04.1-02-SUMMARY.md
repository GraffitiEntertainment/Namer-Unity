## Decisions Made
- `NamerProcessor` composes the `Func<float,float>` evaluate callback (it owns splitter/fitter/decomp state); `NamerRoughnessPipeline` owns only the GPU per-step sharp-removal and the fit cache (3A).
- The fit-driven strength search runs synchronously on cache miss inside `NamerProcessor.Process`, reusing a pre-`Process` split; the refit then consumes `NormalizedBaseColor` (already the cleaned base) so D-05 is satisfied by construction.
- `RoughnessExtractStrength`/`RoughnessEstimator` settings + `NamerEditorConstants` defaults were pulled into Task 2 because `NamerProcessor`'s settings copy and the fit tests need them (the plan listed them under Task 3).
- `NamerComputeResult.NormalizedBaseColorOwnedByRoughnessPool` (internal bool) tracks the D-05 repoint so `ReleaseResult` returns the cleaned base to the roughness pool — the compute pool's `Release` would silently no-op on it and leak.
