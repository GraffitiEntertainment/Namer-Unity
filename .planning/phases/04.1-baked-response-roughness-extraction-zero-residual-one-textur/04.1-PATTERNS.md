### `Compute/NAMERRoughness.compute` (compute-shader, transform)

**Analog:** `Compute/NAMERAO.compute` (staged-kernel structure + separable blur) and `Compute/NAMERDecomp.compute` (max-reduce).

**Header + include + kernel pragma block** (`NAMERAO.compute` lines 1-27):

**RWTexture / Texture / uniform declaration convention** (`NAMERAO.compute` lines 30-66). Note `uint2 _Size` is `unsigned` so kernel guards compare it against `SV_DispatchThreadID` (uint):
```hlsl

Texture2D<float4> _BaseColorIn; // blit-uploaded input (never kernel-written)
uint2 _Size; // unsigned: compared against SV_DispatchThreadID (uint) in the kernel guards
```

**Kernel bound-guard idiom** (`NAMERAO.compute` lines 68-80 — every kernel starts with this):
```hlsl
[numthreads(8,8,1)]
void CSLuminance(uint3 id : SV_DispatchThreadID)
{
    if (id.x >= _Size.x || id.y >= _Size.y) { return; }
    ...
}
```

**Separable gaussian blur with clamped edge taps** (`NAMERAO.compute` lines 115-156). This is the exact frequency-separator blur to reuse for `CSRoughnessBlurH`/`CSRoughnessBlurV` — copy the `exp(-x²/2σ²)` weight, `clamp((int)id.x + x, 0, _Size.x - 1)` tap guard, and `NamerBlurSample`/`NamerBlurWrite` channel-selectable read/write:
```hlsl
[numthreads(8,8,1)]
void CSBlurH(uint3 id : SV_DispatchThreadID)
{
    if (id.x >= _Size.x || id.y >= _Size.y) { return; }
    float acc = 0.0; float wsum = 0.0;
    for (int x = -_Radius; x <= _Radius; ++x)
    {
        float w = exp(-(float)(x * x) / (2.0 * _Sigma * _Sigma));
        int sx = clamp((int)id.x + x, 0, (int)_Size.x - 1);
        acc += NamerBlurSample(_Src[int2(sx, (int)id.y)], _BlurChannel) * w;
        wsum += w;
    }
    _Dst[id.xy] = NamerBlurWrite(acc / wsum, _BlurChannel);
}
```

**Max-reduce (Sobel global-max normalization):** CORRECTION to RESEARCH Pitfall 3 — a max-reduce ALREADY EXISTS. `NAMERDecomp.compute` `CSReduce` (lines 180-216) already reduces `.g = max` hierarchically (overflow-free, no atomics):
```hlsl
// CSReduce (NAMERDecomp.compute lines 180-216): .r=mean, .g=MAX, .b=mean, .a=min
float maxG = 0.0;
for (uint y = 0; y < 8; ++y)
  for (uint x = 0; x < 8; ++x) {
    uint2 src = id.xy * uint2(8u, 8u) + uint2(x, y);
    if (src.x < _AvgSrcSize.x && src.y < _AvgSrcSize.y) {
      float4 s = _SrcAvg[src];
      maxG = max(maxG, s.g);
      ...
```
The Sobel path should copy this kernel body (write Sobel magnitude into `.g`, reduce `.g` to the global max, then a final normalize pass `saturate(mag / max(mag))`). Do NOT hand-roll a new max-reduce.

**Output-format discipline** (header comment, `NAMERAO.compute` lines 15-16): all write targets LINEAR; `R8G8B8A8_UNorm` for the final roughness texture, `R16G16B16A16_SFloat` intermediates; never sRGB.
