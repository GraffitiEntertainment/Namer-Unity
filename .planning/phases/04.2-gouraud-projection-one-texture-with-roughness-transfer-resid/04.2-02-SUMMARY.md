# Phase 04.2 Plan 02: Removed-Luminance Roughness Transfer Summary

**Signed Rec.601 removed-luma roughness transfer: CSRemovedLuma + CSRoughnessTransferRemap kernels, ExtractTransferRoughness + RemovedLumaP90 pipeline path, and a six-test polarity/headroom/identity suite**

## Accomplishments
- Two new compute kernels in `NAMERRoughness.compute`: `CSRemovedLuma` (signed Rec.601 luma of source-minus-projected into `_RemovedLuma.r`) and `CSRoughnessTransferRemap` (the surviving D-08 consume site with the dip source swapped to `saturate(scalar - strength * removedLuma/max(p90,1e-4))`). The Sobel chain remains intact as the alternate dip source (8 → 10 pragma kernels).
- `ExtractTransferRoughness(scalar, source, projected, w, h, strength)` in `NamerRoughnessPipeline`: dispatches the two kernels with WR-03 try/finally lease discipline, returns a caller-owned UNorm8 roughness RT, and never releases its read-only inputs.
- `RemovedLumaP90`: p90 of `|removed-luma.r|` from a 256² R32G32B32A32_SFloat subsample readback, floored at 1e-4 (flat projection → scalar passthrough, never division-by-zero) — mirrors `RobustSobelScale` but with no trueMax ceiling.
- `NamerRoughnessTransferTests`: six capability-gated `[UnityTest]`s proving flat-projection identity, bright-dips-toward-gloss and dark-raises-toward-matte polarity, strength-0 identity, p90 headroom both-end saturation, and a Rec.601 oracle (delta `(0.3,0,0)` → 0.0897).

## Decisions Made
- `_RemovedLuma` is declared once as `RWTexture2D<float4>` (read-write) and read via the `[]` operator in the remap kernel — HLSL cannot declare the same resource name twice, and the existing `_RoughnessRaw`/`_BlurPing` kernels already use this single-declaration read-write convention (minor refinement of the plan's literal "Texture2D read-only" wording).
- `RemovedLumaP90` reads `|.r|` (unlike Sobel's `.g`) and drops the trueMax ceiling — removed-luma has no precomputed true max; the kernel `saturate` owns the clip at both ends (T-04.2-05).
- EditMode run deferred to the orchestrator's post-wave regression gate (see Issues Encountered).
