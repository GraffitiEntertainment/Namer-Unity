**The preview camera becomes orthographic with one shared yaw+pitch rotation across both panes, orthographic-size zoom, and rotation-invariant pair-plus-gap framing — pinned by five new tests — removing the perspective bias from the transferred-roughness LOOK judgment (UI-03/UI-04).**

## Accomplishments

- `NamerPreviewRenderer` reworked per the locked (amended) 04.2 decision: the perspective `cameraFieldOfView`/`FieldOfView` is gone and the constructor sets `camera.orthographic = true`; `ApplyCamera` pins the camera at `OrthoCameraDistance` with identity rotation, so it never moves for framing or zoom. The two fixed preview lights and both `DrawMesh` calls sharing the one `Quaternion.Euler(_pitch, _yaw, 0f)` are byte-identical — the A/B lighting + pane-sync invariant the decision relies on.
- Orbit keeps the two-axis signature and the ±89° pitch clamp but drops the now-pointless trailing `ApplyCamera()`; `Zoom` scales a clamped `_zoomScale` (`1 - scrollDelta * ZoomSensitivity`, same wheel direction as the retired distance zoom) and mutates nothing else.
- Framing is rotation-invariant: `Frame` computes the bounding-sphere half-extent (`bounds.extents.magnitude`, degenerate fallback 1f) and stores `_framedHalfWidth = HalfSeparation + radius + PreviewGap` / `_framedHalfHeight = radius + PreviewGap`; `Render` applies `OrthographicSizeForAspect(aspect)` from the rect aspect. Six public test-observability accessors expose the state for tests.
- `NamerEditorWindow` class doc comment reworded from "shared orbit/zoom camera" to the orthographic side-by-side model; the `Orbit(current.delta.x, current.delta.y)` / `Zoom(current.delta.y)` input wiring, CR-01 residual binding, debug toolbar, and debounced recomputes are untouched.

## Decisions Made

- The orthographic-size fit is applied in `Render` (where the rect aspect is known), not in `Frame` — horizontal fit depends on aspect, and the pure expression `OrthographicSizeForAspect` is shared by both the camera and the test.
- A 6th accessor `OrthographicSize` (camera's current half-height) was added beyond the plan's listed five so the render test can assert "the camera's applied orthographicSize equals OrthographicSizeForAspect(2f)" without reflection. It is a test-observability accessor in the same spirit as the five the plan listed.
- Test 5 frames the cube first, then orbits, then renders — `Render`'s `EnsureFramed` only re-frames when the mesh changes, so pre-framing isolates the "Render consumes but never mutates the one shared rotation" invariant.
- The full EditMode suite is deferred to the orchestrator's post-wave regression gate (no unity-mcp relay; the live interactive editor holds the project lock). Compilation is verified clean via the recompiled DLLs.
