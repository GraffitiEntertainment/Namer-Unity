<objective>
Close GAP-1 (04.2-HUMAN-UAT.md) — the Removed Detail dip's shiny edges and inert
dip-depth slider. Root cause (code-verified): the transfer remap
`CSRoughnessTransferRemap` computes `mag = removedLuma / p90` and then
`saturate(scalar - strength * mag)` with the pack factor forced to 1
(NamerComputePipeline.cs:171-178, roughnessDipApplied=true). At projection-error
texels (UV seams, triangle-boundary kinks, bright baked speckle) `|luma|` is far above
the p90 normalization scale, so `mag` is 3-20x — the `saturate` pins those texels to
roughness 0 at ANY slider value, while `luma≈0` regions stay at the scalar. The
slider's dynamic range is consumed by saturation: the glossy edges never move, so the
slider reads as inert.

Purpose: the transferred-roughness LOOK is the phase's acceptance instrument (SHDR-02 /
UI-03); the default path must show no shiny edges AND the slider must visibly modulate
gloss variation, while the Sobel fallback stays intact.

Fix direction chosen (from the UAT candidate list): soft-clip the normalized depth —
`mag = clamp(removedLuma / max(p90, 1e-4), -1.0, 1.0)` before the dip. Rationale over
the alternatives: (a) masking UV-seam/triangle-edge texels would require a new seam-mask
kernel + RT + plumbing through three pipeline layers — violates the minimal-change rule;
(b) raising the normalization percentile alone does not stop the top-percentile texels
from saturating to gloss, so it would not remove the shiny edges. The soft-clip is a
two-line kernel change, treats the outliers like the strongest legitimate removed detail
(the roughness floor becomes `saturate(scalar - strength)`, so the slider now modulates
them monotonically), and is backward-compatible with all six existing transfer tests
(verified: `Transfer_P90Headroom_SaturatesBothEnds` still clips at strength 1.0; the
Rec.601 oracle uses a sub-unit mag and is unchanged).

Output: a two-line soft-clip in NAMERRoughness.compute, a corrected comment in
NamerComputePipeline.cs, two new seam-outlier tests, and a live-editor UAT re-run on the
Neo asset.
</objective>

[numthreads(8,8,1)]
void CSRoughnessTransferRemap(uint3 id : SV_DispatchThreadID)
{
    if (id.x >= _Size.x || id.y >= _Size.y) { return; }
    float mag = _RemovedLuma[id.xy].r / max(_LumaP90, 1e-4);
    float roughness = saturate(_ScalarRoughness - _Strength * mag);
    _RoughnessOut[id.xy] = float4(roughness, 0.0, 0.0, 1.0);
}
