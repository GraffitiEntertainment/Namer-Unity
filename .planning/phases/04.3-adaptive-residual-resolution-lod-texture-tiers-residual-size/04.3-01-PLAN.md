<objective>
Replace the strict max-error gate in the adaptive residual-resolution search with a percentile coverage gate (D-01, D-02), add the distinct-named AchievedCoverage statistic (D-03, D-07), and keep the no-rung-passes fallback shape unchanged (D-08). The per-texel within-threshold statistic already exists end-to-end on GPU (CSErrorHeatmap -> _CoverageStat -> CSReduce -> BuildStats) — this plan is C#-only; NAMERDecomp.compute gets ZERO changes (PATTERNS headline).

Purpose: The max-error gate lets a handful of outlier texels force a full-resolution residual; the user observed "99%+ actually looks like it's often good at 512x512". The percentile gate makes the walk pick the lowest rung where the user-chosen fraction of texels stays within tolerance.

Output: Gated pipeline (NamerDecompPipeline.cs), DefaultCoverageTarget constant, re-derived + new percentile gate tests.
</objective>
