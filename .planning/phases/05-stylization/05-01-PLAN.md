Per ref, ONE AT A TIME (never hold N Color[] arrays): texture.isReadable pre-check (OQ-1) — first failure returns ErrorTextureName = texture.name; GetPixels; sRGB detection via TextureImporter.sRGBTexture through AssetDatabase.GetAssetPath (NEVER graphicsFormat — STATE Phase 02 WR-04); explicit sRGB→linear in fixed float math before binning.

  5. Anchors: kAnchorCount = 8 slots initialized deterministically from top-K histogram bins by weighted count (ties broken by bin index ASCENDING — no dictionary-iteration-order leakage), then kKMeansIterations = 8 fixed Lloyd iterations over bin centers.
