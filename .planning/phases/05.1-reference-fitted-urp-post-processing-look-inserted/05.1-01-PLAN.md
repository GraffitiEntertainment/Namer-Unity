<planner_decisions>
Resolved research decision points for this plan (per the orchestrator's constraint that RESEARCH open questions are planner territory):

1. **EV fit (RESEARCH OQ-2 / Pitfall 3):** ship the locked plain mean-luma EV ratio — ev = log2(refMeanLuma / srcMeanLuma), both means in the post-tonemap linear domain (source tonemapped via TonemapLdr; reference sRGB-decoded). The tonemap-compression bias on bright references is documented in the estimator's doc comment as accepted v1 behavior; refinement is a gap-closure option only if UAT shows systematic undershoot.
2. **Curve split (RESEARCH OQ-3):** master curve from luma CDFs; R/G/B curves from per-channel CDFs composed with the master mapping (sequential specification — RGB corrects the residual left after master), so master+RGB never double-correct. Fixed uniform key grid, keys capped by kMaxCurveKeys.
3. **Percentile picks (discretion):** contrast p10/p90 (extractor precedent constants); bloom threshold = p95 of reference sRGB Max3 (kDefaultBloomHighlightPercentile = 0.95f — selective enough to sit above midtones, unlike p90; URP's own default threshold is 0.9 gamma-space).
4. **Saturation statistic (RESEARCH A4):** mean HSV-style chroma (max-min)/max(max, eps) per pixel in the post-tonemap linear domain; ratio ref/src → saturation = clamp((s-1)*100, -100, 100).
5. **von Kries anchor (RESEARCH A2):** gray-world mean chromaticity. gains = LinearToLms(refMean) / max(LinearToLms(srcMean), kEps); both gains and solver candidates normalized to unit geometric mean (decouples the overall-gain axis, which belongs to EV); deterministic alternating-axis golden-section 2D solve over temperature/tint ∈ [-100,100], fixed iteration count.
6. **Histogram resolution:** kPostHistogramBins = 256 fixed bins over [0,1] for CDFs/percentiles (curve LUT bakes at 128 texels; 256 bins give sub-texel percentile resolution). Weighted-bin percentile with linear interpolation between occupied-bin centers (extractor PercentileLuma precedent).
</planner_decisions>
