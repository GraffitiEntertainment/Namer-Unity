## What Was Built

**NamerPostLook** (Editor/Stylize/NamerPostLook.cs, sealed partial SO):
- Serialized state: `References`/`ReferenceWeights` (asset's OWN list, D-05), the fitted-post block re-homed field-for-field from the 5.1 profile (PostTemperature/Tint/ExposureEv/Contrast/Saturation = 0, PostBloomThreshold = URP default 0.9, four neutral-diagonal curves, PostFitFingerprint/PostFitExemplarName), the new `PostBloomIntensity` artist knob (A9, default 1, never written by the fit), and `VolumeWriteFingerprint` (A13).
- Members: `AssignedReferenceCount`, `HasFit`, `IsFitStale` (refs+weights vs fit fingerprint, A10), `IsVolumeStale` (params fingerprint vs write-time stamp, A13), `ComputeFingerprint()` (GUID+weight pipe identity over the own list, null slots skipped, deterministic), `internal ComputeParamsFingerprint()` (all seven floats + every curve time/value key, invariant R; tangents excluded because the Volume bakes through Evaluate), `ClampToCaps()` (reference-list truncation + weight sync + NaN-then-clamp fitted block + intensity knob clamp), `CreateNeutralCurve`/`SanitizeCurve`/`AppendCurveKeys` privates, and the `Assets/Create/NAMER/Post Look` menu via `ProjectWindowUtil.CreateAsset`.
- `public static event Action<NamerPostLook> Changed;` declared here; the raise helper lands in plan 05's editor partial (events are raisable only from the declaring type).

**ApplyToPostLook** (NamerStylePostFit.cs, pure addition — the fit math above it is untouched): copies the seven fitted floats + four curves + fingerprint + exemplar name from `NamerStylePostFitParams` onto a look. No Volume write, no scaling, no `PostBloomIntensity` write — the knob stays artist-owned.

**Asset-targeted writer overloads** (NamerStyleVolumeWriter.cs, after the profile members, before BuildTextureCurve — profile path untouched):
- `ComposeVolumePath(NamerPostLook, settings)` — same GEN-01 formula keyed on the ASSET name, so Unity duplicate ("{name} 1") yields a naturally independent Volume.
- `PreflightWriteGate(NamerPostLook, settings)` — confinement + NamerGenerated check with the own-companion exemption, called before mutation by plan 04/05 transactions.
- `Write(NamerPostLook, settings)` — guards null/unfitted ("Run Fit Look first."), runs `ClampToCaps()` (threat T-05.2-01-01), then the carried-over write discipline with R7 deltas: every parameter applied UNSCALED (no NamerPostLookScale anywhere on this path), `bloom.intensity.value = look.PostBloomIntensity`, curves baked without ScaleCurve, and after the stamp it records `look.VolumeWriteFingerprint = look.ComputeParamsFingerprint()` + `SetDirty(look)` (never SaveAssets).

**Prefs + constants:** `NamerProcessorSettings.PostLookGuid` mirrors StyleProfileGuid exactly (same key pattern, same get/set); `NamerEditorConstants` gains MaxBloomIntensity = 10, PostLookParameterTooltipSuffix, PostLookDefaultAssetName, PostLookCreateDialogTitle. DefaultToneMatch untouched — plan 03 retires it.

**Tests (15 new, all headless EditMode):**
- NamerPostLookTests (9): fresh-instance neutral-identity defaults; ClampToCaps fitted-block sanitization (NaN-then-clamp, URP-default bloom fallbacks); degenerate-curve reset to the neutral diagonal; reference-list truncation + weight sync (NaN → default, range clamp); fingerprint determinism + null-slot skipping; weight-change sensitivity; HasFit/IsFitStale lifecycle (pure comparison — reverting restores); ComputeParamsFingerprint coverage of every float and every curve's time/value keys with baseline restoration; IsVolumeStale flip-on-drift including the unfitted-never-stale guard.
- NamerStyleVolumeWriterTests (+6, existing tests untouched): Write_FromAsset_CreatesVolumeWithFiveComponents (R7 pin — exact full-strength field equality including PostBloomIntensity = 2.25 and a non-trivial master-curve evaluation), StampAndRefitOverwrite, RefusesNonGeneratedOverwrite, RefusesUnfitted (including the `(NamerPostLook)null` cast), RecordsVolumeWriteFingerprint, ComposeVolumePath_IsAssetNameKeyedAtDestinationRoot.
