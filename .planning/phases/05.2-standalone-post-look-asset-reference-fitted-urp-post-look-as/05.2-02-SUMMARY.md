## What Was Built

**ComputeChannelPaneClip (Editor/UI/NamerEditorWindow.cs, after ComputeAlbedoPreviewGeometry):** `internal static Rect ComputeChannelPaneClip(Rect paneRect, Rect visibleBand, out Rect uvRect)` — pure, total, side-effect free. Rect.MinMaxRect intersection of the pane with the visible band; a miss or degenerate band returns exact `Rect.zero` (draw/label/cursor/hit-test all skipped — never an inverted rect that could sneak a draw past a negative-size check). For partial overlap it returns the trimmed rect plus the visible fraction as a bottom-origin UV sub-rect (v measured from the quad bottom, the probe-verified mtv lesson) with `Max(1f, ...)` guarded denominators.

**DrawChannelPanes application:**
- Band derived exactly like DrawAlbedoPreview's: unconditional vertical-scrollbar subtract (content is always taller), horizontal-scrollbar strip excluded when shown, band at `(scroll.x, scroll.y, viewWidth, viewHeight)` in content space. hbar presence detected by the probe-verified overflow law (`row.width > viewWidth + 0.5f`) measured from the toggle row captured Repaint-gated into `_channelToggleRowRect` via GetLastRect immediately after the row's EndHorizontal (degenerate during Layout — the mtv GetLastRect lesson).
- Every pane routes through the seam; draw, tooltip label, Zoom cursor rect, and MouseDown hit-test all derive from the SAME clipped rect (threat T-05.2-02-01 mitigated — no invisible interactive surface extends under the bar); a zero-area clip skips the pane entirely; the neutral no-op `GUI.Box` path for the no-texture case is untouched (regular IMGUI controls are already clipped to the scroll group).
- The Repaint-gated `Graphics.DrawTexture` takes the clipped rect with a per-draw `_UvRect` window set immediately before and identity-reset immediately after (mtv shared-material discipline — panes draw earlier in the frame than the albedo preview, which also sets+resets around its own draw).
- Gap: both slot reservations (the i==5 Vertex Color spacer and the pane slot) stop passing `EditorStyles.toggle` and use `_channelPaneSlotStyle`, a lazily-created zero-MARGIN copy — identical content measurement and padding so column alignment under the toggle row is preserved; only the style-owned vertical margin stacking is removed. No new constant, no inline gap number.

**Unchanged (verified):** `ChannelPaneSize` 48f, the i==5 spacer slot logic, tooltip-only pane labels and their copy, Zoom cursor, click-to-popup (`ShowChannelPopup` now receives the clipped rect, so popups anchor below the visible portion of a partially clipped pane).

**Tests (5 new headless EditMode pins, exact Rect values, all dyadic-binary floats so most assertions carry no tolerance):** full containment returns the pane unchanged with exact identity uv; right-edge trim (vbar side) cuts at the band edge with an exact 0.5 window; bottom-edge trim (hbar strip) yields the bottom-origin v window `[1 − 30/48, 1]`; zero intersection returns exact `Rect.zero` (+ zero window); degenerate first-frame band returns `Rect.zero` (draw skipped — the mtv first-frame guard class).
