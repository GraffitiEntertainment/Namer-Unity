# Phase 5.2 — UI Design Contract (Unity IMGUI)

> Visual and interaction contract for the standalone post-look asset. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> This project is a Unity editor plugin, not a web frontend. Web-template dimensions are translated into Unity IMGUI terms below, inheriting the approved Phase 5 contract (`.planning/phases/05-stylization/05-UI-SPEC.md`) and the Phase 5.1 amendment (`.planning/phases/05.1-reference-fitted-urp-post-processing-look-inserted/05.1-UI-SPEC.md`) verbatim — this phase re-homes that language, it does not invent a new one. New surfaces: a **`NamerPostLook` ScriptableObject with its own custom Editor in the main Inspector** (reference list + Fit action + *editable* fitted parameters + Volume regeneration) and a **Post Look selection row** in the Processor window feeding the existing "Stylized + Post" lens. Removed surfaces: the Tone Match slider, the profile's Fitted Post Look block (P15–P20), and every Tone Match copy reference.

## Design System

| Property | Value |

**Baseline (binding):** the Phase 5 / 5.1 idiom set, now concretely in code — every one of them is a donor for this phase:

- Reference-list idiom (donor): 64×64 thumbnail rows + `miniButtonLeft("+")`/`miniButtonRight("–")` footer appending/removing the LAST slot + count-honesty `miniLabel` (`DrawReferenceSlots :111-146`, `DrawReferenceFooter :149-180`, `DrawCountLine :183-190`) — **the asset's reference list mirrors the footer, count line, and weights verbatim (D-05 weights/slots mirroring untouched); the per-row thumbnail is deliberately NOT mirrored (user-directed amendment 2026-09-27): each row is a `Reference Texture #N` label + ObjectField, the ObjectField's built-in thumbnail being the only image preview on the row**
- Visible-band clip idiom (donor, quick 260926-mtv): Repaint-gated widget-rect capture + band-intersection clip so clipped regions are removed from the draw, never stretched or overdrawn under a scrollbar/header (`ComputeAlbedoPreviewGeometry` + `_UvRect` sub-rect window, `NamerEditorWindow:2262-2290`, `:2333-2375`) — **the channel-pane strip inherits this defect class's fix (W14)**
- Read-only stats idiom: `boldLabel` header + tooltip'd `LabelField(label, value)` rows, `"—"` placeholder before data, staleness Warning HelpBox (`DrawStatistics :270-294`) — survives only as the constant "Tonemapping" row
- Slider value-edit idiom: `EditorGUI.BeginChangeCheck` → `Undo.RecordObject` → write → `SetDirty` → raise `Changed` (`DrawSlider :652-663`) — **the asset's editable fitted parameters reuse this verbatim, retargeted to `NamerPostLook`**
- Lens popup idiom: `After View` `EditorGUILayout.Popup` with decision tooltip + debounce sentence, flip → `_afterView`/`_settings.AfterView` + `MarkTweaking()` + `MarkDirty()` (`NamerEditorWindow:1479-1498`) — unchanged, tooltip copy amended (W11)
- Honesty-line idioms: `DescribeProfileState` `miniLabel` (`:2643-2660`), disabled-with-reason lens fallback HelpBox (`:1513-1520`), count-honesty line — every disabled/degraded state carries a visible reason; no silent dead controls
- Create-and-attach idiom: `SaveFilePanelInProject` → `CreateInstance` + `CreateAsset` + GUID attach + `PingObject` + `MarkDirty` (`CreateAndAttachStyleProfile :2229-2249`) — **"Create Post Look…" copies this exactly**

- Debounce: `NamerEditorConstants.DebounceSeconds = 0.3f` — the named constant, never an inline number; the debounce suffix sentence appears only on controls that recompute the window preview and write nothing to disk

**Focal point:** the `NamerPostLook` main Inspector's loop — **Fit Look → tweak the fitted sliders/curves → Regenerate Volume** — closing the per-scene look workflow without leaving the Project window. Secondary focal: the Processor window's Post Look row lighting up the existing "Stylized + Post" lens. (Checker rec — Visuals dimension.)

## Spacing Scale (IMGUI translation — inherited from Phase 5/5.1)

IMGUI auto-layout owns vertical rhythm; the contract constrains the exceptions we control.

| Token | Value | Usage |
|-------|-------|-------|
| Row spacing | platform default (`EditorGUIUtility.standardVerticalSpacing`, 2px — Unity-owned, declared exception) | All control rows — never padded manually |
| Group gap | one `EditorGUILayout.Space()` | After the reference-list block, after the Fit block, after the parameters block — exactly as existing groups do |
| Foldout indent | one `EditorGUI.indentLevel++` (platform 15px — Unity-owned, declared exception) | Advanced foldout only (per-reference weights), default collapsed |
| Channel-pane strip gap (W14) | one platform row spacing (2px class) under the shaded-view toggle row — NO style-margin stacking | The pane strip reads as directly attached to its toggle row; today's gap is style-owned (see W14) — an authorable override, if layout forces one, is a named constant ≤ 4px (multiple-of-4 law), never an inline number |

Exceptions: none beyond the two Unity-owned/declared values above (2px row spacing, 15px indent). No fixed-size elements on this phase's new surfaces — the post-look reference rows carry no separate thumbnail (user-directed amendment 2026-09-27); the ObjectField's built-in preview is the only image. The palette profile's 64px thumbnail (`kThumbnailSize`) remains a Phase 5/05.1 surface constant, and the window's existing 48px `ChannelPaneSize` remains a Phase-3-era declared value — both untouched by this phase (W14 changes only the pane strip's gap and clipping).

### C. Serialization, constants, generated-asset naming, migration

- `NamerPostLook` serialized state: reference list + weights (mirror the profile's list shape), fitted block (the retired profile fields move home: params, curves, fit fingerprint over the asset's own references, exemplar display name), defaults neutral (0 EV, 0 contrast/saturation/WB, `DefaultBloomThreshold`, `DefaultBloomIntensity`, identity curves — unfitted ≡ neutral ≡ no post). `ClampToCaps` moves onto the asset with the NaN-then-clamp precedent. A `Changed` event mirrors `NamerStyleProfile.Changed`, with the partial raise helper beside the asset editor (declaring-type-only law, STATE precedent); the window subscribes while this asset is selected so edits refresh the debounced preview.
- Reference bounds: `MaxReferences` (10) caps the slot list, mirroring the slot UX; the minimum gate is ≥1 positive-weight readable reference (the frozen fit's zero-mass guard) — the palette extractor's min-3 is deliberately NOT imported (the count line A4 states the honest gate). Header reads "Reference Images" without a count range.
