# Phase 05.3 Plan 04: Merge Dialog Summary

**One-liner:** Tools/NAMER "Merge Style Assets…" EditorWindow plus the headless-pure `NamerStyleAssetMergerCore` (profile-first first-wins GUID-dedup reference union, element-wise palette carry, deep stats/curve copies, honest not-decomposed state, ClampToCaps close) with cap honesty evaluated at a count seam before any asset exists — pinned by an 8-test suite covering no-silent-loss, union order, cap boundary, state honesty, source immutability, and clamp-on-merge.

## What Was Built

### Task 1 — `NamerStyleAssetMerger.cs` + merge-dialog constants (commit 6e4438f)

- **`NamerStyleAssetMergerCore` (internal static, headless-pure):** `BuildMerged(profile, look)` — ArgumentNullException on null profile; (1) reference union via the one-home `AppendUnionReferences` (profile's non-null refs first with per-slot weights, then the look's non-null refs whose GUID is not already seen — first-wins keeps the PROFILE slot's weight; null slots skipped; empty GUIDs exempt from dedup so distinct in-memory textures never conflate); (2) palette block (anchors element-wise, `CopyStats` field-by-field deep copy, `ReferenceFingerprint` verbatim, both palette-source ints → `kPaletteSourceRaw`); (3) fitted-post block when look ≠ null (all seven floats verbatim, `CopyCurve` = `new AnimationCurve(curve.keys)` with null passthrough, fit/exemplar/volume fingerprints); (4) sliders + HueMode from the profile; decomposition/validation fields left at neutral defaults (M3); closes with `ClampToCaps()` (T-05.3-04-01). `CountUnionReferences(profile, look)` runs the SAME walk into throwaway lists and returns the count — the dialog's cap gate and the real merge can never diverge.
- **`NamerStyleAssetMerger` (public EditorWindow):** `[MenuItem("Tools/NAMER/Merge Style Assets…")]`; two ObjectFields (Style Profile required / Post Look optional); preview miniLabel (with-look and look-less locked formats, `AssignedReferenceCount` counts); cap HelpBox MessageType.Error + `EditorGUI.DisabledScope(_profile == null || capExceeded)` around the button — both reading `CountUnionReferences` BEFORE anything is created (M3); RunMerge = SaveFilePanelInProject (default "{profileName} Style") → BuildMerged → `AssetDatabase.CreateAsset` → `SaveAssets` → `PingObject` → announcement `Debug.Log` (M4 never silent). Zero delete/move/SetDirty calls anywhere — sources are never touched (M5). Class doc records the Volume-orphan consequence (source look's Volume orphans in place; 05.2 R8 precedent, never deleted silently).
- **`NamerEditorConstants.cs`:** 12-constant merge-dialog strings block (window title, field labels, both preview formats, button label, save-dialog name suffix/extension/message, cap-error format, both announcement formats) — all user-visible merge copy in one home, Unicode ellipsis/em-dash verbatim from the locked M-series spec.

### Task 2 — `NamerStyleAssetMergerTests.cs` (commit 9794223, 8 tests)

1. **No-silent-loss:** 4 anchors with awkward floats (`0.1f + 0.2f`) asserted element-wise in invariant "R" format (the ComputeParamsFingerprint law); 13 stats fields deep-copied (`AreNotSame` + field-for-field); every Post float "R"-equal; curve time/value keys equal per key (tangents excluded — precedent) with `AreNotSame` instance pins; all three fingerprints + exemplar name verbatim; sliders + HueMode carried.
2. **Union order + duplicates:** profile [A, null, B] + look [B(dup), null, C] with real imported PNG textures (real GUIDs) → exactly [A, B, C]; the duplicate keeps the PROFILE weight (0.25, not the look's 0.9); `CountUnionReferences` == 3 before anything is built.
3. **Look-only union:** empty profile refs → look's refs append in order with weights verbatim.
4. **Cap honesty:** 6 + 6 distinct imported refs → seam counts 12 > MaxReferences; BuildMerged deliberately NOT called in that state (button gate is UI; the seam value is the proof). Boundary sub-assert: two duplicates drop the union to exactly 10 = cap, which must NOT trip the strict greater-than gate.
5. **State honesty, with look:** IsDecomposed false, palette non-empty, HasFit true, both palette-source ints == kPaletteSourceRaw, DecompositionFingerprint/GradeSourceExemplarName/ValidationResult/ValidationFingerprint all empty (decomposition does NOT auto-run).
6. **State honesty, look-less:** palette carries, HasFit false, post block at neutral identity (no fit fabricated), raw flag still applies.
7. **Sources untouched:** full serialized dumps (ComputeFingerprint + ComputeParamsFingerprint + field-level anchor/stats/slider and provenance-string dumps) captured before BuildMerged and asserted byte-identical after — the merge reads, never writes back (M5).
8. **ClampToCaps on merge:** 12-reference (over-cap) profile with weights 2.5/NaN/−0.5 → merged lists truncated to MaxReferences, weights clamped 1/default/0.

Isolation discipline: temp folder `Assets/NAMER_Style_Merge_Tests_Temp` with `EnsureTempFolder` + `AssetDatabase.DeleteAsset` in `finally` on every test creating assets (3 tests), in-memory fixtures destroyed in `finally` everywhere else, no sleeps.
