# Phase 5.3 — UI Design Contract (Unity IMGUI)

> Visual and interaction contract for reference scene decomposition + the merged style asset. Generated by gsd-ui-researcher.
> This project is a Unity editor plugin, not a web frontend. Web-template dimensions are translated into Unity IMGUI terms below, inheriting the approved Phase 5 contract (`.planning/phases/05-stylization/05-UI-SPEC.md`), the Phase 5.1 amendment (`.planning/phases/05.1-.../05.1-UI-SPEC.md`), and the Phase 5.2 contract (`.planning/phases/05.2-.../05.2-UI-SPEC.md`) verbatim — this phase merges two surfaces into one, it does not invent a new language. New surfaces: **ONE merged style asset with ONE custom Editor** (shared weighted reference list → ONE explicit decomposition → HSL palette block + fitted post block + confidence stats + Volume block + forward validation) and a **menu-only creation path** (`Assets/Create/NAMER/…`) plus a **merge dialog** for migrating existing `NamerStyleProfile` + `NamerPostLook` pairs. Removed surfaces: the window's "Create Post Look…" and "Create Profile…" buttons, the window's Post Look row, the window's embedded profile inspector, and the asset-side "Fit Look" button (superseded by Decompose Style).

## Design System

| Property | Value |
|----------|-------|
| Tool | none (Unity Editor IMGUI — shadcn gate not applicable; not a React/Next.js/Vite stack) |

**Baseline (binding):** the Phase 5 / 5.1 / 5.2 idiom set — every one of them is a donor for this phase:
- Reference-list idiom (5.2 `NamerPostLookEditor` + quick-260928-lm5 amendment): "Reference Images" `boldLabel` header + `miniLabel` help line; **material-inspector slot rows** — "Reference Texture #N" `GUILayout.Label` LEFT + square 64px (`kThumbnailSize`) `EditorGUILayout.ObjectField` RIGHT whose built-in preview is the thumbnail (`DrawReferenceSlots :115-148`); `miniButtonLeft("+")`/`miniButtonRight("–")` footer appending/removing the LAST slot with copy-locked tooltips (`DrawReferenceFooter :155-186`); count-honesty `miniLabel` (`DrawCountLine :193-200`); Advanced foldout with per-reference weight sliders (`DrawAdvanced :208-241`) — **the merged asset's shared list mirrors all of this exactly**
- Explicit-action button idiom (5.1/5.2): `Extract Style Stats` / `Fit Look` → busy label swap, `DisabledScope(busy ‖ prereq-unmet)` with exactly ONE visible reason `miniLabel`, synchronous run with cancellable progress bar, `Undo.RecordObject` + `EditorUtility.SetDirty` write, Error HelpBox below — **Decompose Style and Validate Look copy this idiom exactly**
- Editable-parameter idiom (5.2 A9): sliders/CurveFields inside `DisabledScope(!fitted)` with the unfitted reason; every edit `BeginChangeCheck` → `Undo.RecordObject` → write → `SetDirty` → raise `Changed`; write-suffix tooltip (`NamerEditorConstants.PostLookParameterTooltipSuffix`), NOT the debounce suffix (`DrawParametersBlock :475-555`, `DrawSlider :673-684`) — **the merged asset's post block reuses this verbatim**
- Read-only stats idiom (5.1 P18 / 5.2): `boldLabel` header + tooltip'd `LabelField(label, value)` rows, `"—"` placeholder before data (`DrawStatistics`, `NamerStyleProfileEditor:232-244`) — **the decomposition-confidence rows and validation result reuse this**
- Stylization-slider idiom (5.1/5.2, `NamerStyleProfileEditor:260-294`): `EditorGUILayout.Slider` with decision tooltip + debounce suffix — **Style Strength / Smoothing / Cavity Floor / Normal Detail / Roughness Simplify carry over verbatim onto the merged asset**
- Asset-menu idiom: `[MenuItem("Assets/Create/NAMER/Style Profile")]` + `ProjectWindowUtil.CreateAsset(…, "New Namer Style Profile.asset")` (`NamerStyleProfile.cs:247-253`, `NamerPostLook.cs:392-396`) — **the merged asset's menu item mirrors it**
- Volume block idiom (5.2 A11–A14): status line + Regenerate Volume + staleness Warning + per-scene hint (`DrawVolumeBlock :586-639`) — **carried over byte-for-byte, retargeted to the merged asset (05.2 D-06 carries over per W4)**
- Lens popup + fallback idiom (5.1 W5/W6, 5.2 W9/W10): `After View` popup with decision tooltip + debounce sentence; honest degrade + `MessageType.Info` reason; disabled states always carry a visible reason — **retargeted to the single attached merged asset**
- Migration honesty idiom (5.2 M2): never silent — the created asset is pinged and a console line names it — **the merge dialog inherits it**
- Debounce: `NamerEditorConstants.DebounceSeconds = 0.3f` — the named constant, never an inline number; the debounce suffix sentence appears only on controls that recompute the window preview and write nothing to disk; explicit-action controls never carry it

**Focal point:** the merged asset inspector's loop — **Decompose Style → review the palette + confidence stats → tweak the post sliders → Regenerate Volume → Validate Look** — the whole reference-to-style workflow in one Inspector, with the Processor window reduced to a single attach field. ## Spacing Scale (IMGUI translation — inherited from Phase 5/5.1/5.2)

IMGUI auto-layout owns vertical rhythm; the contract constrains the exceptions we control.

| Token | Value | Usage |
|-------|-------|-------|
| Row spacing | platform default (`EditorGUIUtility.standardVerticalSpacing`, 2px — Unity-owned, declared exception) | All control rows — never padded manually |
| Group gap | one `EditorGUILayout.Space()` | After the reference-list block, after the Decompose block, after the Palette block, after the Post block, after the Volume block — exactly as existing groups do |
| Reference-row thumbnail | 64×64 px (`kThumbnailSize`) | The shared list's slot rows — material-inspector style, label left + square ObjectField right (quick-260928-lm5 donor, carried verbatim) |
| Foldout indent | one `EditorGUI.indentLevel++` (platform 15px — Unity-owned, declared exception) | Advanced foldout only (per-reference weights + Hue Mode), default collapsed |
| Palette swatch | inline read-only `ColorField` at default control height within the palette row | Data display, not layout chrome — one swatch per palette color row (S12) |

Exceptions: none beyond the two Unity-owned/declared values above (2px row spacing, 15px indent). No new fixed-size elements beyond the carried 64px thumbnail. The window's existing 48px `ChannelPaneSize` and 96f+10f debug-strip grid are untouched by this phase.

## Color (Unity Editor skin — zero custom UI colors, inherited)

| Role | Value | Usage |
|----------|-------|------|
| Dominant (60%) | Editor window default background | Everything |
| Secondary (30%) | Standard control chrome (sliders, popup, curve fields, color fields, boxes, foldout arrows) | Everything |
| Accent (10%) | NONE custom — this phase introduces zero hex values | reserved for: nothing (Unity skin supplies the default button/accent) |
| Destructive | none (no destructive-colored actions — see Copywriting) | — |

**Data-display exemption (declared):** the palette block's read-only `ColorField` swatches (S12) display the EXTRACTED palette colors as data — the same class of exemption as the reference rows' 64px texture thumbnails. They are not UI chrome color; the zero-custom-color law governs chrome only. Swatches render inside `DisabledScope` (read-only — the palette is derived data; hand-editing a fitted/derived palette is out of scope and would break the fingerprint).

Semantic color = `MessageType` mapping only: `Warning` (decomposition staleness, palette-source staleness, Volume staleness, validation mismatch), `Error` (decompose/validation/merge failures), `Info` (lens fallback reasons, no-asset hints, LUT-fallback unlock notice context). The post lens must NOT be distinguished by color — the popup selection and pane content carry it (skin parity rule, Phase 5).
