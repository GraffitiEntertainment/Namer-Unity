<authoritative_section_inventory>
Derived from NamerEditorWindow.OnGUI() draw order (lines ~841-859). Document these regions IN THIS ORDER. Every label below is verbatim from the code — do not invent or rename sections.

1. **Stage & Shader Gates** (DrawStepSwitches, no foldout — pinned above the scroll content)
   - Bold header "Stage & Shader Gates" + miniLabel help line
   - Five ToggleLeft checkboxes: "VC + Residual", "Roughness", "AO" (pipeline-STAGE gates — take effect on the next Process run), "Metallic", "Emissive" (SHADER-ONLY gates — live, no re-Process needed)
   - Each toggle persists via NamerProcessorSettings
2. **Source** (DrawSourceSection, foldout)
   - Shows selection name + type; lists each material as "name — ShaderName"; warning HelpBoxes
   - Empty states: "No source selected" / "No materials found" with guidance
   - Accepted selections: GameObject, prefab, model, material, or folder
3. **Preview/Debug** (DrawPreviewSection, foldout)
   - "Before" / "After" caption row; one combined preview render, both panes share ONE orthographic camera (synced rotation)
   - Camera input: plain drag = orbit; Ctrl+drag = pan; Shift/Ctrl/Alt+scroll = zoom (plain scroll scrolls the dialog)
   - Shaded-view input toggle row (7 checkboxes, shader-only, no GPU recompute, not persisted): "Base/Residual", "Roughness", "AO", "Metallic", "Emissive", "Vertex Color", "Normal" — each neutralizes the matching input in the After view
   - Channel pane row (6 panes, 48px): "Base" (decodes _BaseResidualMap), "Roughness", "AO", "Metallic", "Emissive", "Normal" (decode _SurfaceMap) — all through the shared NAMER decode (what the runtime material sees, no drift). Click a pane = 384px popup (ShowAsDropDown, click-away closes)
   - "Triangles" toggle: wireframe second pass over the After pane (visual debug only, cyan lines)
   - Neutral gray boxes when no generated textures exist yet
4. **Roughness Extraction** (DrawRoughnessExtractionSection, foldout)
   - "Dip Source" popup: "Removed Detail" (default — re-expresses removed luminance as gloss; requires VC decomposition enabled) / "Sobel Edge" (fallback, Blender-parity edge signal)
   - "Roughness Dip Depth" slider 0–1, default 0.25 (0 = keep authored roughness scalar)
   - Info HelpBoxes when the effective dip source falls back to Sobel Edge
5. **AO** (DrawAoSection, foldout) — MUST document the post-b75d925 contract:
   - An authored `_OcclusionMap` on the source material ALWAYS transfers, regardless of the AO gate
   - The Stage & Shader Gates "AO" checkbox gates SYNTHESIS only: OFF + no authored map = surface B packs WHITE (no synthetic AO at all); ON + no authored map = the geometry bake is the synthetic source
   - Four sliders: "AO Un-multiply Strength" 0–1 default 1 (un-multiplies baked AO out of the base color), "AO Blur Radius" 0–16 texels default 0, "AO Strength" 0–1 default 1, "AO Contrast" 0–4 default 1 (pivot 0.5)
   - All four sliders respond LIVE without re-Process: 0.3 s debounce, in-memory GPU recompute, nothing written to disk; the un-multiply strength is independent of the AO gate (white surface B makes the divide an identity)
6. **Decomposition** (DrawDecompositionSection, foldout)
   - "Vertex Color Decomposition" toggle (default OFF — opt-in): fits the base color into mesh vertex colors; preview shows the decomposed reconstruction; Process writes the seam-split mesh (+ residual EXR when enabled)
   - Warning HelpBox when decomposition will be SKIPPED for this selection (multi-material/multi-mesh CR-01 guard) — preview and Process both show/generate the non-decomposed result
   - "Write Residual Texture" toggle (default OFF = one-texture outcome: no residual EXR; the Gouraud projection already whitens base ÷ vertex-color). ON = additionally write the removed detail as an EXR
   - "Error Threshold" slider 0–0.10 default 0.02 and "Residual Resolution" popup (Auto/2048/1024/512/256/128, default Auto) — enabled ONLY when Write Residual is on; disabled + hint line otherwise
   - "Statistics" block (read-only, "—" before first fit): "Coverage" %, "Avg Error", "Max Error", "Removed-detail max error", "Residual" ("not written (one-texture)" or "written @ Npx")
   - Status line: "Recomputing preview…" / "Preview up to date"
7. **Output** (DrawOutputSection, foldout)
   - "Destination" (default Assets/NAMERGenerated/), "Prefix" (default empty), "Suffix" (default "_Namer"), "Overwrite generated" toggle
   - Source assets are never modified; generated output lives only in the destination folder
8. **Action** (DrawActionSection — pinned OUTSIDE the scroll view, always reachable)
   - "Process with NAMER" button (label becomes "Processing…" while busy; disabled while busy or recomputing); status HelpBox (info/error, e.g. "Generated N material(s) under ...")

Entry points for the Getting Started section (menu items, verbatim): "Tools > NAMER > Processor" opens the window; "Assets > Process with NAMER" and "GameObject > Process with NAMER" context-menu commands run Process immediately with default settings and log results to the console.
</authoritative_section_inventory>
