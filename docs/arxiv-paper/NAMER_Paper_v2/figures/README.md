# Figures

The raster figures in this directory are copied from `docs/images/` in the NAMER Unity project and are embedded directly by `namer_paper.tex` so the paper source is self-contained.

- `preview-before-after.png`: synchronized Unity editor before/after material preview.
- `decomposition-section.png`: vertex-color decomposition controls and diagnostic statistics.

The screenshots are illustrative implementation figures, not aggregate benchmark results.
